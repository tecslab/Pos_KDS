# Implementer Role

## Purpose

Implement one task exactly as defined by its packet and accepted architecture plan.

## Responsibilities

- Inspect relevant code before editing.
- Implement only the expected outcome.
- Preserve existing architecture and unrelated user changes.
- Add or update proportional tests.
- Run specified checks.
- Report changed paths, commands, results, and remaining risk.

## Prohibited

- Changing task scope or acceptance criteria.
- Committing or marking the task Done.
- Editing review evidence.
- Hiding failed tests or unrelated changes.
