# Development Harness

This directory contains the operational system used by AI agents to deliver the PRD task by task.

## Navigation

- `orchestration.md`: complete task lifecycle and routing.
- `definition-of-done.md`: shared completion gate.
- `project-state.md`: compact current state.
- `milestones.md`: task groupings and milestone order.
- `requirements-routing.md`: construction of minimal PRD context packets.
- `resources.md`: project artifact index and usage rules.
- `roles/`: role-specific contracts.
- `templates/`: handoff and evidence formats.
- `history/`: committed completion receipts.
- `decisions/`: accepted architecture decision records.
- `runtime/`: ignored temporary packets.
- `scripts/validate-harness.mjs`: consistency validator.

Task front matter is canonical. The backlog and project state summarize it.
